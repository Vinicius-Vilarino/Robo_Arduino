Apresentação

Este trabalho foi desenvolvido como parte da disciplina de Sistemas Operacionais do 3° Semestre do curso de Análise e Desenvolvimento de Sistemas da faculdade Anhanguera. O projeto consiste na montagem e desenvolvimento do código de um robô seguidor de linha com processador Arduino. O objetivo principal é aplicar conceitos de programação, eletrônica e lógica computacional para criar um robô seguidor de linha autônomo.
